Kidic Parenting Assistant

Internship Project · Solo AI Build

A retrieval-augmented generation (RAG) chatbot built for Kidic, a parenting/childcare app, during my AI engineering internship at EgronX. I owned every part of the AI stack alone — retrieval pipeline, LLM integration, conversational memory, per-child personalization, and deployment — while the rest of the team built the app's Spring Boot/Laravel backend.

The problem

New parents have a constant stream of small, urgent questions — is this food safe, how much sleep is normal, is this behavior a red flag — and generic chatbots either answer with unsourced confidence or are too generic to account for one child's specific age, allergies, and health notes. Kidic needed an in-app assistant that answers from a curated pediatric/parenting knowledge base, remembers the conversation, personalizes answers to the child on file, and — critically for a health-adjacent product — knows when to say "I don't know" and point a parent to a professional instead of guessing.

How a question flows through the assistant

Six stages run on every message, from the parent's question to a grounded, personalized reply.

  1. Parent asks a questionA message comes in through the chat API, tied to the parent's session.
  2. Rewrite with historyA LangChain history-aware retriever rephrases follow-up questions into standalone queries using prior chat turns.
  3. Retrieve knowledgeThe query is embedded and matched against a curated pediatric/parenting corpus in a Qdrant vector collection.
  4. PersonalizeThe child's profile — age, allergies, medical notes — is pulled and injected into the prompt alongside the retrieved context.
  5. Groq LLM answersA Groq-hosted Qwen3-32B model generates a concise, empathetic reply grounded in the retrieved context — or admits it doesn't know.
  6. Session memory updatesThe exchange is saved to a trimmed per-user history (last 3 turns) so the next question has context.

What I built

I was the only AI engineer on the internship team — everything below is mine, end to end.

RAG pipeline
Retrieval
Built the retrieval-augmented generation pipeline with LangChain: embedded a curated pediatric/parenting knowledge base with HuggingFace sentence-transformer models and served it from a vector store. Started with a local FAISS index, then migrated the whole retrieval layer to a managed Qdrant cloud collection on a dedicated Git branch for production scalability — without breaking the working FAISS version teammates were relying on.
LLM & memory
Conversation
Integrated a Groq-hosted Qwen3-32B model for low-latency responses and implemented a history-aware retriever so the assistant correctly resolves follow-up questions ("what about at night?") using prior turns, backed by trimmed per-user session memory.
Personalization & safety
Prompt design
Designed the prompting layer to inject structured child-profile data (age, allergies, medical notes) into every answer, and added guardrails appropriate for a health-adjacent product: concise, empathetic tone, and an explicit "I don't know — consult a professional" fallback when a question falls outside the knowledge base.
Shipping
Iteration & deploy
Iterated the assistant through four stages — a Jupyter notebook prototype, a Streamlit demo UI, a monolithic FastAPI service, then a refactored modular production API (routers/services/schemas) — and containerized the final version with Docker for deployment as a Hugging Face Space.
